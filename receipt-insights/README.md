# Receipt Insights

Локальный анализатор банковской выгрузки/чеков в CSV. Нормализует категории, считает расходы по месяцам и показывает повторяющиеся покупки. Полезен для ответа «куда уходит бюджет?» без загрузки финансовых данных в облако.

## Запуск

```bash
pip install -r requirements.txt
python report.py sample.csv
```

Ожидаются столбцы `date,description,amount,category`; сумма — числом в единой валюте. Отрицательные суммы трактуются как расходы, положительные — доходы/возвраты. Файл примера синтетический. Не загружайте настоящую выписку в публичный репозиторий.
