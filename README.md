# Data Analytics Portfolio

Учебное портфолио: прикладные проекты на Python, SQL, статистике и работе с API. Для каждого проекта есть отдельная папка и собственный README.

## Проекты

- `cs2-market-watch/` — снимки цен предметов CS2 из Steam Market в SQLite.
- `internship-radar/` — поиск вакансий и зарплатных диапазонов через HeadHunter API.
- `receipt-insights/` — локальная аналитика транзакций CSV: расходы, категории, повторяющиеся траты.
- `fx-budget/` — пересчёт бюджета по курсам ЦБ РФ.
- `air-quality-commute/` — почасовой прогноз PM2.5/PM10/озона и поиск менее загрязнённых часов.
- `ab-test/` — анализ A/B-эксперимента на синтетических данных.
- `product-sql/` — SQL-воронка, удержание когорт и оконные функции.
- `classification-metrics/` — метрики бинарного классификатора и выбор порога.

Учебные наборы явно помечены как синтетические. В API-проектах фактические результаты зависят от доступности и условий источников. Это портфолио демонстрирует код и подход; не следует заявлять о бизнес-эффекте, которого проекты не измеряли.
