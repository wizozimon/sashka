# A/B-тест: влияние нового оформления на конверсию

Учебный анализ синтетического эксперимента интернет-магазина. Цель — определить, увеличивает ли новый вариант страницы долю пользователей, оформивших заказ.

## Вопросы

- Случайно ли распределены пользователи между группами (SRM-проверка)?
- Какова конверсия каждой группы и абсолютный/относительный эффект?
- Совместимы ли данные с отсутствием эффекта на уровне значимости 5%?
- Какой практический вывод можно сделать, учитывая неопределённость?

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
python analyze.py
```

## Данные

Скрипт генерирует фиксированный синтетический набор на 20 000 пользователей. В реальном эксперименте до анализа нужно проверить единицу рандомизации, период, дубли, ботов, пересечения групп, SRM и заранее выбранную основную метрику.

## Метод

Двусторонний z-тест для двух долей с pooled-оценкой при нулевой гипотезе; 95% Wald-интервал для разницы долей. Для производственного анализа лучше применять согласованный с командой метод (например, interval/Newcombe или bootstrap), а также учитывать множественные проверки и дизайн эксперимента.
