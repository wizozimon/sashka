# Air Quality Commute

Загружает почасовой прогноз PM2.5, PM10 и озона для координат города, выводит ближайшие часы с наименьшей концентрацией PM2.5 и сохраняет результат в CSV. Сценарий — выбрать время прогулки/поездки на велосипеде по прогнозу.

## Запуск

```bash
pip install -r requirements.txt
python commute.py --lat 55.7558 --lon 37.6173 --hours 24
```

Данные Open-Meteo Air Quality API основаны на моделировании/прогнозе, а не на локальном датчике возле пользователя. PM-показатели в API описаны как значения для соответствующего часа; не трактуйте их как медицинскую рекомендацию. Укажите атрибуцию Open-Meteo/CAMS при публикации результатов.
