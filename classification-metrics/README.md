# Метрики бинарной классификации и выбор порога

Учебный проект показывает, почему accuracy может вводить в заблуждение при редком положительном классе. На синтетических вероятностях строится таблица ошибок, затем рассчитываются precision, recall, F1, specificity и balanced accuracy для разных порогов.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
python metrics.py
```

## Важное ограничение

Синтетические вероятности нужны только для демонстрации метрик. Порог нельзя выбирать по тестовой выборке: его подбирают на validation-наборе с учётом цены ошибок и бизнес-ограничений, а итог оценивают отдельно на test-наборе.
