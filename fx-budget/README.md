# FX Budget Planner

Пересчитывает бюджетные строки в выбранную валюту по официальным ежедневным курсам Банка России, сохраняет исходную сумму и дату курса. Практический сценарий — планирование поездки/покупок в другой валюте и проверка влияния курса на бюджет.

## Запуск

```bash
pip install -r requirements.txt
python convert.py --date 2026-11-06 --base USD --amount 250 --target RUB
```

Источник: XML API курсов ЦБ РФ. Курсы могут публиковаться не для выходных/праздничных дат; используйте фактическую дату публикации и проверьте результат для нужной даты. Это справочный расчет, не курс платежа/обмена.
